# Русский язык для детей — Ренада Александровна

Одностраничный сайт услуги: диагностика и сопровождение изучения русского языка детьми.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | весь сайт — разметка и оформление в одном файле |
| `hero.png` | главная фотография |

Никаких сборщиков и установок: файл открывается двойным кликом в любом браузере.

## Как поменять текст

Откройте `index.html` в блокноте или редакторе кода. Текст лежит внизу файла,
между `<body>` и `</body>` — правьте прямо там.

## Как поменять цвета

В самом начале файла, в блоке `:root`, перечислены все цвета сайта:

```
--bg        #FDFBF7   основной фон
--bg-soft   #F3EBE0   бежевые полосы
--accent    #B08968   кнопки и акценты
--accent-bg #C9AD93   заливка коричневой полосы
--ink       #3E2F26   цвет текста
--footer    #4A3A2E   подвал
```

Меняете значение в одном месте — цвет обновляется по всему сайту.
